# Nha Sach Tri Tue - PHP thuan

Project PHP thuần + PDO + MySQL, không dùng Laravel hay Composer.

## Cài đặt

1. Import `database.sql` vào MySQL/phpMyAdmin.
2. Sửa thông tin MySQL ở `config/config.php`.
3. Đặt thư mục vào `C:\xampp\htdocs\nhasach-php-thuan`.
4. Mở `http://localhost/nhasach-php-thuan/login.php`.

Tài khoản demo:

- Email: `admin@nhasach.local`
- Mật khẩu: `1234`

Có dashboard, quản lý sách, xóa sách, danh mục, khách hàng và lịch sử bán hàng.
